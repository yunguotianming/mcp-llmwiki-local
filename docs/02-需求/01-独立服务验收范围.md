# 独立服务验收范围

> 更新日期：2026-11-16。记录独立服务需求 FR-01～FR-10 与当前同步基线的验收标准。

## 1. 用户目标

| 编号 | 需求 | 验收标准 |
| --- | --- | --- |
| FR-01 | 不安装 dsh 也能查询和建立本地 Wiki | AC-01：给定构建产物，启动 stdio MCP，列出 19 个工具并完成查询，原作业接口继续有效 |
| FR-02 | 登记和移除本地资料库，保留用户文件 | AC-02：给定空配置目录，CLI 增列删成功，删除登记后资料和库文件仍存在 |
| FR-03 | 支持异步生成预览、查看状态、确认发布和取消 | AC-03：给定假模型与 Markdown，生成立即返回 ID，状态包含预览、缺口和成本，正确摘要签名提交后可查询 |
| FR-04 | 沿用单设备写锁与现有库布局 | AC-04：给定源协议持有的活进程锁，后发生成明确报告正在被占用；新库采用 data 分区 |
| FR-05 | 兼容模型支持本机明文密钥或环境变量引用，查询理解失败可降级 | AC-05：本机配置允许 apiKey 或 apiKeyEnv，二者互斥，同时填写时拒绝；日志、公共输出及随库文件不含密钥。给定缺失 DeepSeek 密钥，原话检索成功并标注 understanding 降级 |
| FR-06 | 保留本机/云端向量与纯全文，以及复制换模 | AC-06：假嵌入测试验证向量、全文检索和复制后保留内容；MCP 复制工具提供显式确认与异步状态 |
| FR-07 | 独立维护且便于回补同步 | AC-07：共用核心文件与对照表明确的固定源提交 Git blob 一致；对照表列出复制、适配和排除范围 |
| FR-08 | 共用 0.3.0 多模型策略、接受恢复、生产记录与升级 | AC-08：假模型验证阶段选择、暂停换模型、已接受成果复用及协议两种接口；独立配置保留原外层，凭据双入口与隔离边界按 AC-05 验证 |
| FR-09 | CLI/MCP 共用库管理、发现和卡片资源 | AC-09：库卡片可读可订阅，修订冲突拒绝覆盖，CLI 更新组织字段保留 runtime；原 library 命令和配置目录不变 |
| FR-10 | 首次建库前解释颗粒度并取得用户选择，避免无提示地采用默认档位 | AC-10：给定尚无建库成果的新库，未选择时返回待选择及极简、粗放、适中、标准、细致、精细、自定义的覆盖深度、核对强度和成本差异，不创建生成作业或调用模型；明确选择后保存并生成。自定义上限须为 1～500 的整数；说明数量为上限而非必须凑足，预设按篇幅扩额。已有成果及可恢复任务沿用原颗粒度，不静默覆盖；初始化或保存失败后不得绕过选择继续生成 |

## 2. 范围与依据

本仓独立发布，预览版为 0.3.0-preview.1；首次迁移基线是 `ff449031f899b53bc3342adae89008e536a69c26`，0.3.0 共用代码首轮同步基线为 224ff7f，后续修复按固定源提交逐次同步，准确文件与取舍见[源仓库文件对照](../06-验收与测试/01-源仓库文件对照.md)。本轮提供本地 Markdown 建库及已登记 Wiki 查询。dsh 设置页、宿主 HTTP、自动维护、模型路由注入与原生 keeper 工具不进入独立服务；依赖这些文件的本地网页工作区暂不同步。宿主专属测试不迁移，思源混合测试保留核心协议验收、移除 Cordis Schema 断言。首次迁移结果见 [首次迁移验证](../06-验收与测试/02-首次迁移验证.md)，当前同步与验收状态见[进度清单](../00-项目进度/01-项目进度.md)。FR-10 是预览发布后的新增要求，其实现及验收状态也按进度清单记录，不追认到已发布包。
